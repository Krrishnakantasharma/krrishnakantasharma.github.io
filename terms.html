1. What the App Does

HTG GameZone is a utility application that provides the following features:

  • Device Stats Monitor: View real-time RAM usage, storage breakdown, battery status, temperature, and network information
  • Game Launcher: A convenient launcher to start your favorite games with optional Do Not Disturb mode, Screen-On toggle, and Rotation Lock
  • Game Toolbox: An optional floating overlay displaying live stats (RAM, battery, temperature, FPS) and quick controls including DND toggle, rotation lock, FPS counter, cache cleaner, and DNS changer — last two require Shizuku
  • Advanced Tweaks (Shizuku-based): Optional system setting adjustments requiring separate Shizuku installation
  • Module Flasher: Apply pre-made configuration modules in .turbox format (requires Shizuku)
  • App Manager: View installed apps and uninstall via the standard Android uninstall flow
  • Storage Analyzer: View files by category, detect duplicates, and delete files via system confirmation
  • Network Check: Test ping latency, DNS resolution, and connection details
Important: The App does not claim to make your device faster or guarantee performance improvements. All features display information or modify standard Android settings that you could also change manually in Android Developer Options or system settings. Results vary by device.

5. Game Toolbox and Overlay

The Game Toolbox is an optional floating overlay requiring the "Display over other apps" permission, which you must grant voluntarily. The overlay runs as a foreground service and shows a persistent notification as required by Android.

Toggle features (DND and Rotation Lock)

These require separate permissions (DND access and Modify System Settings respectively). If these permissions are not granted, the corresponding toggles are visibly disabled with instructions on how to grant them. They will never silently fail.

Clear All Cache (Shizuku required)

When Shizuku is active, this button uses Android's pm trim-caches command — the same API used by Android's own Settings app — to clear cached data for all apps. This removes only temporary cache files. No user data, app data, accounts, or settings are modified. When Shizuku is not active, this button is disabled.

DNS Changer (Shizuku required)

When Shizuku is active, this allows you to change your device's Private DNS setting to Cloudflare (1.1.1.1), Google (8.8.8.8), or Auto (system default) for faster DNS resolution. This affects DNS resolution for all apps on the device, not just games. When Shizuku is not active, this button is disabled. You can revert to Auto (default) at any time.

6. Module Flasher

The Module Flasher executes .turbox module files selected by you. All commands within modules are validated and sanitized before execution — dangerous operations (root commands, file deletion, reboots, etc.) are blocked at parse time. Modules from third parties are the responsibility of their authors. Only use modules from trusted sources (official HTG channels). The "Reset All" option can undo any module's changes.

7. Storage Analyzer

File deletion performed through the Storage Analyzer is permanent and cannot be undone by the App. All deletion requires your explicit confirmation via the system dialog. Duplicate detection uses file size and MIME type matching — verify files before deleting. The Developer is not responsible for accidental file deletion.
